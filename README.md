# Nitrogen (N2)

A personal wiki that lives in a GitHub repo: clean wiki UI (tree, backlinks, rich blocks), a PWA for
phone and web, and a remote MCP server so Claude can read and write the same repo from anywhere.
Markdown is the truth; every write is a commit; everything exports to standard markdown.

Status: pre-release, under construction. See `docs/` and `packages/spec/SPEC.md`.
